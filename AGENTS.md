# Repository guidance

This repository contains Minalu's Angular portfolio website and a portable professional profile.

For CVs, cover letters, job proposals, career facts or profile updates, start with [career-profile/README.md](career-profile/README.md) and follow [career-profile/AGENTS.md](career-profile/AGENTS.md). That directory is self-contained and can be read by any agent from a clone.

For a profile/portfolio check-in, a bare request to continue, or the profile-maintenance skill, read `career-profile/HANDOFF.md` and `career-profile/TASKS.md` at the start. Check unfinished plan items and missing profile evidence, then complete the supplied task or offer up to three next actions. Do not request another background recap. Use `.agents/skills/profile-maintenance/SKILL.md` for the maintained workflow. A specific unrelated website fix should keep its requested scope rather than starting a career check-in.
