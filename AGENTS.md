# Repository guidance

This repository contains Minalu's Angular portfolio website and a portable professional profile.

For CVs, cover letters, job proposals, career facts or profile updates, start with [career-profile/README.md](career-profile/README.md) and follow [career-profile/AGENTS.md](career-profile/AGENTS.md). That directory is self-contained and can be read by any agent from a clone.

Website code lives in `src/`. Career profile updates do not automatically update or publish website content. Preserve unrelated work in the working tree. Do not add private career supplements or generated applications to Git.
